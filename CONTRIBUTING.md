# Contributing

Thanks for helping improve BOF3 Lighthouse Bot.

## Bug reports

Please include:

- Windows version
- DuckStation version
- graphics backend
- display resolution
- Windows display scaling
- whether the game is running at 100% speed
- whether F7 successfully sends K
- F9 diagnostic output
- what F8 reports
- any timing adjustment that worked (for example, `F6 once`)

Screenshots or a short recording are especially useful for visual-detection bugs.

## Pull requests

Keep changes focused and explain:

- what problem is being fixed;
- how the change was tested;
- whether it affects graph detection, marker detection, timing, or input delivery.

Please preserve AutoHotkey v2 compatibility.
