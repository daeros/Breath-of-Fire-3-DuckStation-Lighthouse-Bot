# Security Policy

This project is a small local AutoHotkey script and does not use a network service.

Please report security-sensitive issues privately to the repository maintainer rather than posting exploit details publicly.

The script:

- activates a local DuckStation window;
- reads screen pixels;
- sends a keyboard event;
- requests elevated privileges when needed to match the target application's integrity level.

Review the source before running it, especially if you download it from anywhere other than the official repository.
