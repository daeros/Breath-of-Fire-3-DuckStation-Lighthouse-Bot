# Changelog

All notable public changes to this project will be documented here.

## [1.0.0] - 2026-09-05

### Added

- Automatic DuckStation window activation.
- Automatic Lighthouse boiler graph detection.
- Four-marker synchronized flash detection.
- Live cycle-period measurement from two consecutive flashes.
- Predictive input timing.
- Default successful lead of **140 ms before the predicted flash**.
- F5/F6 timing adjustment in 20 ms increments.
- F7 K-input test.
- F9 visual-detection diagnostics.
- F10 clean exit.
- 1 ms Windows timer-period request for tighter scheduling near the target time.
- DuckStation executable-name fallbacks.

### Notes

This is the first public release. Earlier internal prototypes are intentionally not part of the public version history.
